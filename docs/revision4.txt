Recommended Testing Workflow

For each revision, use this status flow:

Pending → In Development → Fixed → For Client Testing → Passed → Closed

For every item marked Fixed, the client should be given a simple verification procedure:

Steps to Test → Expected Result → Actual Result → Status → Remarks

This makes it clear to the client which revisions are already fixed and exactly how they can verify each one, rather than simply marking an item as completed.
