Admin Role & System-Wide Enhancements
• Admin Activity Logs Pagination: Displays 6 recent entries by default
with an Expand option to view full history. (Fixed)
• Placeholder Labels: Replaced placeholder account labels with
standardized default names (e.g., School Head, Admin). (Fixed)
• Usernames Display: Replaced system usernames with actual full names
across the system. (Fixed)
• Profile Security: Mandatory manual input required for the "Current
Password" field during profile updates with autofill disabled. (Fixed)
• Username Validation: Added specific syntax and constraint rules for
username creation and changes. (Fixed)
• Sidebar Navigation: Moved the sidebar collapse/expand toggle button
directly into the navbar instead of the page body (expanding flips the
brand logo). (Fixed)
• User Guide Flowchart: Added an easy-to-follow PDF system guide with
explanations for non-technical users. (Fixed)
🍎Teacher Role Features & Fixes

year. (Fixed)
• My Sections View: Removed the global "All Sections" view so teachers
only see "My Sections" (specifically assigned teaching sections). (Fixed)
• Subject & Document Filtering: Document Management section filters
files to display only those relevant to the teacher's designated subjects.
(Fixed)
• Grade Change Requests: Added a field for common mistakes when
requesting grade modifications. (Fixed)
• Upload Grades Template: Fixed formatting issues in the
downloadable/uploadable grade entry template. (Fixed)
• School Form (SF) Generation: Restricted SF generation exclusively to a
teacher's assigned students. (Fixed)
• Student Management & Status Updates (Recently Enrolled List): Shows
6 recent students by default, with an Expand button to view the rest.
(Fixed)
• Student & Enrollment Updates (Graduated Students): Graduated
students can no longer be re-enrolled; accounts automatically
lock/archive to preserve historical section and academic data. (Fixed)
